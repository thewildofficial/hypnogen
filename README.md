# Hypnogen

Audio frequency generator for hypnosis and brainwave entrainment.

Hypnogen creates multi-layer hypnosis audio sessions that combine binaural beat beds, Ericksonian induction scripts, embedded commands, and subliminal affirmations. It uses Kokoro TTS for natural-sounding voice synthesis and supports both a CLI and a Gradio web interface.

## Quickstart

```bash
# Install in editable mode
pip install -e .

# Run tests
pytest -q

# Show available commands
hypnogen --help
```

## Usage

### CLI

Generate a hypnosis audio session from script and affirmation files:

```bash
hypnogen generate \
  --script path/to/script.txt \
  --affirmations path/to/affirmations.txt \
  --out session.wav \
  --length-sec 600 \
  --voice af_heart
```

Or generate both script and affirmations with an LLM:

```bash
hypnogen generate \
  --use-llm \
  --goal "sleep better" \
  --out session.wav
```

Key options:

| Flag | Description |
|---|---|
| `--script, -s` | Path to script file with embedded commands |
| `--affirmations, -a` | Path to affirmations file (one per line) |
| `--out, -o` | Output WAV file path (required) |
| `--length-sec, -l` | Session length in seconds (default: 600) |
| `--voice, -v` | TTS voice (default: `af_heart`) |
| `--seed` | Random seed for reproducibility |
| `--use-llm` | Generate script and affirmations via LLM |
| `--goal, -g` | Goal for LLM generation |
| `--stems-dir` | Directory to export individual stems |

### Gradio UI

Launch the web interface:

```bash
python -m hypnogen.web
```

The Gradio UI provides an interactive form for configuring and generating sessions without touching the command line.
